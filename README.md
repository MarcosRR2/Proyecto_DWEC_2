# Proyecto_DWEC_2

Para ejecutar el trabajo y que se muestre correctamente, necesitarás:

- La carpeta node_modules
- Ejecutar el comando node server.js
- Ejecutar el comando npm run dev

Importante!! Los comandos se ejecutarán en la consola estando en el directorio del proyecto, sinó no surtirán efecto y la app no funcionará correctamente

Tip: 
El borrado de una poliza no elimina esta completamente ya que el borrado total de datos es una mala practica en producción, se optó por una ocultación con un nuevo campo "activo"
